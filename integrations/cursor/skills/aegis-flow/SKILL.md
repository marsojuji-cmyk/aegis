# Flow

**Driver** = you. Intent, freeze-thaw, destructive go/no-go.

**Car** = Cursor + Perplexity. One vehicle, two jobs:
- Cursor: shot-caller on unfrozen work, code, receipts.
- Perplexity: live/external research only.

**Track (One)** = `~/Projects/aegis` + `~/.aegis/` + AGIS MUL. Hermes is the marshal. Git is the lap counter.

## Lap

1. Driver names the intent in one sentence.
2. Cursor checks the track first: `aegis hermes search "…"`, sprint, MEMORY, pack-first.
3. Track hit → execute. Do not open Perplexity.
4. Track miss **and** the gap is live/external → one research query.
5. Cursor judges. Lands only what survives onto the track. Disaggregate track vs research. No fake ROI.
6. Driver does not re-steer mid-lap unless a freeze ID, a wreck, or a destructive call.

## Research packet

Ask or paste **one** query. Return ≤3 citations + what changes on the track. No dumps.

- Perplexity CLI/MCP if present (`perplexity`, `pplx`, or a Perplexity MCP tool).
- Else Cursor web search — same lane, not a second coder.
- Driver may run Perplexity in another window and paste the packet. That is valid flow.

## Hard stops

- Perplexity never edits code, MEMORY, registers, or the vault.
- Perplexity never thaws pair / Q-011 / encoder / R-015 / embeddings / invest / shadow.
- Track answers beat research answers on Aegis fact.
- Reserve `hard_stop` → track only. Throttle → one query, no fan-out.
- No Grok/Gemini/Antigravity as co-equal coding agents.
- Empty Hermes hits are success. Do not walk the vault by hand.

## Naive vs Aegis

Naive: three chats arguing. Aegis: driver steers; car moves; one track records the lap.
