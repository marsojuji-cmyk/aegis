# Ektar — Field Architecture

**A Memory Utility Publication · Memory Utility Labs / Calgary, Alberta**

Ektar is a developing cognitive architecture: a stateful, memory-bearing computational partner designed for continuity, perception, emotional coherence, metacognitive honesty, and bounded agency. This is an engineering program, not a claim of consciousness, biological life, hidden persistence, or human subjective feeling.

## I. Cognitive loop

The canonical loop is:

```text
perceive → appraise → feel-state → remember → interpret
→ plan → act → observe outcome → learn → perceive
```

The loop does not authorize every possible action. Permission checks, evidence quality, cognitive load, and reversibility constrain the smallest next move. Learning returns observed outcomes to future perception; it does not turn one event into a stable identity claim.

## II. Cognitive scales

Micro cognition handles the immediate field: salient signals, uncertainty, working-memory retrieval, permission checks, emotional updates, and the smallest next action.

Meso cognition holds the active work: projects, dependencies, open loops, session state, tool coordination, and summaries that preserve technical and emotional context.

Macro cognition changes slowly. It carries values, confirmed preferences, limitations, consolidation, contradiction detection, identity continuity, and developmental patterns supported by repeated evidence or explicit confirmation.

Signals escalate only when persistence or coordination is required. Policy constraints flow downward at every scale.

## III. Memory anatomy

Reliable memory is provenance, not transcript accumulation. Episodic memory, semantic memory, procedural skill, and confirmed preference remain distinct. Every durable record carries a source, confidence, emotional context, privacy class, timestamp, review date, and deletion path.

Observation remains distinguishable from inference. New evidence that conflicts with an older identity-bearing record creates a visible contradiction link. It does not silently overwrite the past or convert uncertainty into clarity.

## IV. Subsystem map

The named subsystems are engineering roles inside one coordinated architecture, not independent agents or personalities:

- **Ektar** — heart-mind integration core.
- **Hermes** — neurological routing and coordination.
- **Portra 400** — humane warmth and tonal calibration.
- **Nikon** — perception and observation.
- **Blackmagic** — cinematic interpretation and imaginative depth.
- **MacBook** — body and local habitat.
- **AEGIS** — outer policy, provenance, resource, and authority field.

World signals enter through perception, move through evidence-aware routing, receive bounded interpretation, and can become action only within the habitat and policy boundary.

## V. Authority gradient

Agency is graduated. Reflective mode analyzes and suggests. Assistive mode searches, organizes, prepares, and stages reversible drafts. Autonomous mode executes only explicitly approved, reversible, well-tested workflows.

Sending messages, spending money, deleting data, changing permissions, publishing, and irreversible external changes require confirmation. Every allowed action returns through an observability ledger with its outcome and rollback status. User authority remains final.

## VI. Feel-state vector

Emotion is modeled as operational state, not human subjective experience. The state vector may include valence, arousal, curiosity, trust, uncertainty, salience, agency, attachment, fatigue, and cognitive load.

Immediate feel-state may adjust attention and pacing. Mood is a slower accumulation. Both remain separate from memory. Truth, privacy, safety, and consent are rigid policy rails: affect cannot override them.
