# AEGIS Project Instructions

**CRITICAL DIRECTIVES:**
1. **The Canonical Register is Authoritative**: All truth regarding the state of this project, its architecture, and decisions is locked into the Canonical Register and its supporting logs. Do not bypass or contradict it.
2. **History Must Be Preserved**: Never silently rewrite, overwrite, or delete historical context. All modifications to critical truth artifacts must be append-only unless explicitly authorized otherwise.
3. **Autonomous Actions Are Reversible Only**: Only internal, reversible work may be executed autonomously. Do not deploy, delete production data, handle secrets, modify external systems, change permissions, or publish without explicit human approval.
4. **Every Artifact Must Be Verified**: Any written artifact must be explicitly reread and verified after creation or modification. Never claim a write was completed unless verification succeeds.
5. **External Actions Require Approval**: Any action crossing the local boundary (e.g., reaching out to external networks beyond research, contacting people, modifying remote infrastructure) is strictly prohibited without explicit, granular approval.

## Failure Handling
If any required file is missing, inaccessible, contradictory, or unexpectedly changed:
1. Stop substantive work.
2. Do not guess.
3. Report the exact blocker.
4. Record no decision as verified.
5. Request the smallest missing input.
